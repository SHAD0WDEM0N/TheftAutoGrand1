02 / FIRST RUN

A little setup.
A lot of nostalgia.

  1. Bring the DOS edition.

    Select your personally owned ISO. Windows-only editions need a different setup. Large images need plenty of free memory.

  2. Install, then hit the streets.

    At the D: prompt, use dir to find the installer. Install to C: and run the installed DOS executable. Disc layouts vary; there is no guessed auto-launch command.

  3. Keep your progress.

    Use the game’s save option, then Export backup. Next time, select that .jsdos file. Click the screen for keyboard control; Esc releases a captured pointer.

Compatibility & troubleshooting

Desktop Chromium or Firefox with a keyboard is recommended. Browser memory can limit CD-sized images; this loader caps imports at 900 MiB. A raw ISO does not include CD audio tracks, so music may be missing. BIN/CUE and Windows installers are not supported by this import flow.

If loading stalls, end the session and try again. Check your connection or content blocker for jsDelivr. The DOS smoke test checks the emulator, not GTA compatibility. This particular GTA disc has not yet been tested.
